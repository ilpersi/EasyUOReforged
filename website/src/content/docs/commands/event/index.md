Event commands cause the Ultima Online client to use one of its available internal macros.

| Command | Summary |
|---|---|
| [event ContTop](/commands/event/conttop/) | Brings a gump to the front |
| [event Drag](/commands/event/drag/) | Drags an object |
| [event ExMsg](/commands/event/exmsg/) | Shows a message over the object given by the ID |
| [event Macro](/commands/event/macro/) | Performs a UO internal macro |
| [event PathFind](/commands/event/pathfind/) | Moves you to a specified position if it is possible |
| [event Property](/commands/event/property/) | Reads the property description of an item |
| [event SkillLock](/commands/event/skilllock/) | Changes the skill locks on the different skills |
| [event Sleep](/commands/event/sleep/) | Suspends the client for a specified time (not implemented in Reforged) |
| [event StatBar](/commands/event/statbar/) | Opens the health bar of a character |
| [event SysMessage](/commands/event/sysmessage/) | Outputs text to the client as a system message |
