kind: subcommand
category: menu
syntax: "menu Combo ( {\"Create\"} {name} {x} {y} {width} )  |  ( {\"Add\"} {name} {text} )  |  ( {\"SELECT\"} {name} {index} )"
source: wiki
---

The [menu Combo](/commands/menu/combo/) command creates a combobox at position x/y with specified size on the EasyUO menu window or adds entires to the combobox. Select defines what entry is currently showing, similar to [menu Set](/commands/menu/set/).
