---
title: "menu Image Line"
description: "Draws a line within a specified image."
kind: subcommand
category: menu
syntax: "menu Image Line {name} {x1} {y1} {x2} {y2} {color} [width]"
source: wiki
---

The [menu Image Line](/commands/menu/image/line/) command draws a line from x1/y1 to x2/y2 within the specified image.

For the color parameter, you can use names like "red", "yellow" or "windowtext" or use a hexadecimal number like $AABBCC (BBGGRR encoded). You may also specify a line width (default is 1).
