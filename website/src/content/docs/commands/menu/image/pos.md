---
title: "menu Image Pos"
description: "Moves an already existing image control to a different position."
kind: subcommand
category: menu
syntax: "menu Image Pos {name} {x} {y} [width] [height]"
source: wiki
---

The [menu Image Pos](/commands/menu/image/pos/) command moves an already existing image control to a different position. You can use the width and height parameters to enlarge or shrink the image.
