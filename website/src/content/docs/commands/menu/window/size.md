category: menu
syntax: "menu Window Size {width} {height}"
related: ["menu Show", "menu Window Title"]
source: wiki
---

`menu Window Size` sets the size of the menu window's inside, in pixels: the area controls are placed in,
without the title bar and borders.

## Example

```euo
menu Window Size 300 200
```
