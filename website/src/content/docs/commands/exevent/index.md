ExEvent commands send packet information directly to the Ultima Online server in order to perform actions.

## Exevents

The exevents are version 1.5+ only, and the available exevents are as follows..

| [exevent Drag](/commands/exevent/drag/) | Drags an object using packets |
|----|----|
| [exevent Dropc](/commands/exevent/dropc/) | Drops an object in a given container using packets |
| [exevent Droppd](/commands/exevent/droppd/) | Drops wearable items into the paperdoll |
| [exevent Equip](/commands/exevent/equip/) | Equips one or more items by ID in one request |
| [exevent Dropg](/commands/exevent/dropg/) | Drops an object on the ground using packets |
| [exevent Popup](/commands/exevent/popup/) | Opens the context menu of an item/npc |
| [exevent RenamePet](/commands/exevent/renamepet/) | Renames a pet |
| [exevent SkillLock](/commands/exevent/skilllock/) | Changes the skill locks on the different skills |
| [exevent StatLock](/commands/exevent/statlock/) | Changes the stat locks on the different stats |
