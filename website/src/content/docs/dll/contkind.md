`ContKind` is a read-only property: the same value as [`#ContKind`](/variables/contkind/), returned as a number.

Kind of the gump on top, as a code; tells crafting menus, runebooks and more apart.

IDs come back as plain numbers, not as the letter codes the `#` variable shows.
