`LHandID` is a read/write property: the same value as [`#LHandID`](/variables/lhandid/), returned as a number.

ID of the item for the left hand; set it, then event Macro 24 1 arms it.

IDs come back as plain numbers, not as the letter codes the `#` variable shows.
