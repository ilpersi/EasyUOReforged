`RHandID` is a read/write property: the same value as [`#RHandID`](/variables/rhandid/), returned as a number.

ID of the item for the right hand; set it, then event Macro 24 2 arms it.

IDs come back as plain numbers, not as the letter codes the `#` variable shows.
