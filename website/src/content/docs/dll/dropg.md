Drops the item last dragged on the ground, like `exevent DropG`. Default height: your own.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `x` | number | X position. |
| `y` | number | Y position. |
| `z` | number | Height. |

## Returns

Nothing.
