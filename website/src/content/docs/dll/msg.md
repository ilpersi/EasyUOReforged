Types text into the client, like `msg`. Unlike the command, `$` is not Enter: put a carriage return (character 13) at the end to send it.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `text` | string | The text. |

## Returns

Nothing.
