`LTargetID` is a read/write property: the same value as [`#LTargetID`](/variables/ltargetid/), returned as a number.

ID of the last object targeted; set it, then event Macro 22 targets that object.

IDs come back as plain numbers, not as the letter codes the `#` variable shows.
