Runs one of the client's macros, like `event Macro`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `macro` | number | Macro number, as for `event Macro`. |
| `parameter` | number | Macro parameter. |
| `text` | string | The text. |

## Returns

Nothing.
