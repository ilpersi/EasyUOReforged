Presses a key in the client, like `key`.

## Parameters

| Parameter | Type | Meaning |
|---|---|---|
| `key` | string | Key name, as for `key`. |
| `ctrl` | boolean | Hold Ctrl. |
| `alt` | boolean | Hold Alt. |
| `shift` | boolean | Hold Shift. |

## Returns

Nothing.
