Holds the value of the last message box button that was clicked.

| Value  | Button               |
|--------|----------------------|
| OK     | "Ok" was clicked     |
| CANCEL | "Cancel" was clicked |
| YES    | "Yes" was clicked    |
| NO     | "No" was clicked     |
