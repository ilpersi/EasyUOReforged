Every built-in `#variable`. Most are read-only and describe the client (your character, the last
target, the last `FindItem` search…); a few can be set to change what the script or the client
does. Type in the box to filter, pick a category, or show only read/write variables. Press
<kbd>Ctrl</kbd> <kbd>K</kbd> anywhere to search the whole site.
