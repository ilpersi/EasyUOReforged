## What a script looks like

```euo
; drink a heal potion when hits drop below half
loop:
if #Hits < #MaxHits / 2
{
  finditem UUF C_ , #BackpackID     ; yellow potion
  if #FindCnt > 0
  {
    set #LObjectID #FindID
    event macro 17 0                 ; use it
  }
}
wait 10
goto loop
```
